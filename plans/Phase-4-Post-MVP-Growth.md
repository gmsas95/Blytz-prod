# Phase 4: Post-MVP Growth

### 1. Monitoring
- **Task:** Monitor app health and user behavior with Firebase.
- **AC:**
    - **Crashlytics:** Monitored daily for stability issues.
    - **Performance:** Tracked to identify regressions.
    - **Analytics:** Configured with custom events for key funnels (checkout, bidding, etc.).
    - Dashboards are created to visualize core funnels.

### 2. User Feedback Loop
- **Task:** Establish channels for user feedback.
- **AC:**
    - `HelpSupportScreen.tsx` provides clear contact info.
    - A system for tracking and prioritizing feedback is in place.

### 3. Post-MVP Feature Development
- **Task:** Begin development on deferred features based on feedback.
- **AC:**
    - A clear, prioritized product backlog is maintained.
    - Sprints are used to deliver iterative improvements.
    - Potential features: i18n, advanced search, user-to-user chat, detailed seller analytics.

### 4. Infrastructure Scaling
- **Task:** Optimize backend infrastructure for growth.
- **AC:**
    - Firestore queries are reviewed for cost and efficiency.
    - Firebase Cloud Functions are monitored and optimized.
    - IVS streaming setup is reviewed for scalability.
    - A scaling plan for logistics and payment services is developed.
